I have published a new portfolio proof of concept on IT third-party technology dependency mapping. It uses fictional service and provider records to show shared-provider concentration and unconfirmed dependencies as prompts for human review. The code is deterministic and does not assess actual supplier risk, discover hidden dependencies, or certify resilience. The project builds on my work in service continuity and vendor management, with a narrow focus on how providers are shared across services.
